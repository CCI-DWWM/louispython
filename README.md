# 🐍 louispython

Bienvenue dans **louispython**, une collection d'exercices Python simples et éducatifs pour apprendre les bases de la programmation.

## 💻 Création du VENV

Pour créer un environnement virtuel Python :

```bash
py -m venv venv
```

## 📁 Contenu des exercices

✅ Exercice 1 : Âge de l'utilisateur
Demande à l'utilisateur son année de naissance et calcule son âge actuel.

🔢 Exercice 2 : Nombres pairs
Affiche tous les nombres pairs jusqu'à une limite donnée par l'utilisateur.

✖️ Exercice 3 : Factorielle d'un nombre
Calcule et affiche la factorielle d'un nombre entier positif.

🔤 Exercice 4 : Compter voyelles et consonnes
Analyse une phrase saisie par l'utilisateur et compte le nombre de voyelles et de consonnes.

🔍 Exercice 5 : Nombre premier
Teste si un nombre donné est un nombre premier.

🟩 Exercice 6 : Carrés d'un nombre
Affiche les carrés des nombres de 1 jusqu'à une limite définie par l'utilisateur.

🧪 Exercice 7 : Test de primalité (bis)
Deuxième version du test de nombre premier, avec une approche différente ou optimisée.
